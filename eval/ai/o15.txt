以下は、非エンジニアの経理担当者向けにまとめた **freee と kintone の連携手順概要（約350字）** です。

1. **目的と連携イメージを確認**  
   - freee の取引データ（仕訳・請求書等）を kintone の業務アプリに自動で取り込み、レポート作成や承認フローを一元化します。

2. **freee 側で API 利用設定**  
   - freee の管理画面にログインし、左メニューの「アプリ連携」→「API」から「APIキー」を発行。  
   - 発行したキーはコピーして安全な場所に保管します（後で kintone 側で使用）。

3. **kintone 側でアプリ作成**  
   - kintone にログインし、業務で管理したい項目（例：取引日、勘定科目、金額）をフィールドとして持つカスタムアプリを作成。  
   - 必要に応じてプラグインやビューを設定し、一覧や集計が見やすいようにレイアウトを整えます。

4. **kintone の API トークン取得**  
   - 作成したアプリの「設定」→「API トークン」から新規トークンを発行し、**閲覧・追加** 権限を付与。  
   - トークンも同様にコピーして保管します。

5. **連携ツール（Zapier・Microsoft Power Automate・Make など）を選定**  
   - コーディング不要で使える iPaaS ツールを利用すると手軽です。  
   - 例：Zapier の場合「freee → New Transaction」トリガーと「kintone → Create Record」アクションを組み合わせます。

6. **Zap/Zflow の設定**  
   - **トリガー**：freee の API キーを入力し、取得したいデータ種別（仕訳・請求書等）を選択。  
   - **アクション**：kintone の API トークンとアプリ ID を入力し、freee の項目を kintone のフィールドにマッピング。  
   - フィールドの対応付けは画面上でプルダウンから選ぶだけです。

7. **テスト実行と動作確認**  
   - freee にサンプル取引を作成し、Zap が正しく kintone にレコードを作成するか確認。  
   - エラーが出たらマッピングや権限設定を見直します。

8. **自動実行の有効化**  
   - テストが成功したら Zap をオンにし、定期的に（例：1時間ごと）自動でデータが同期されるようにします。  

9. **運用とメンテナンス**  
   - 取引が増えても問題ないか定期的にレコード数や API 使用上限を確認。  
   - 変更が必要になったら Zap の設定を更新すれば完了です。

これらの手順を順に行えば、プログラミング知識がなくても freee と kintone のデータ連携が実現できます。
